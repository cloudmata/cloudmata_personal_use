# xxx_personal_use

很久以前，在一所很大的学校里，住着一只小老鼠。

当然，他不是一开始就住在机房里的。

他小时候其实学过很多东西。

他下过很久的棋，国际象棋下得尤其久。他从低级棋士一路跳级，最后到了一级棋士。有一段时间，他甚至觉得自己大概会一直下下去。

可是某一个夏天以后，他忽然没有再去学棋了。

没有发生什么特别大的事情。

就是没有去了。

很多年以后他偶尔想起来，还会觉得有一点遗憾。

小老鼠还曾经被选去参加过一次很重要的选拔。

那是城里最好的学校举办的信息学选拔。

他高高兴兴地去了，然后第一轮就被刷掉了。

因为别人都准备了语文和英语，只有他不知道。

这件事他记了很久。

倒也不是因为输不起。

只是觉得：

“凭什么啊。”

那时候的小老鼠不知道，这一点小小的不服气，后来会把他带进一间机房。

小老鼠的爸爸是一只做 IT 很多年的老狐狸。

小老鼠自己也很喜欢电子游戏。

于是，在棋还没有下完、那次选拔也没有争回来的很多情绪里，他跑去参加了信息学竞赛。

那时候他还只是一个刚上初中的小孩。

他对高中有很重的幻想滤镜。

在他眼里，高中是一座遥远得不得了的城堡，里面有厉害的人，有新的生活，有一种他还说不清楚的东西。

所以他其实很兴奋。

初中入学第二周，他就跑进了机房。

然后很奇怪的事情发生了。

他没有特别喜欢教室。

他也没有特别喜欢操场。

但他喜欢机房。

机房里的电脑一排一排地亮着，门总是半掩着，里面的人可以上网，可以讨论自己喜欢的东西，可以偷偷玩游戏，可以为了一个奇怪的算法争上半天。

而且还有发光的耳机！

更重要的是，那里有朋友。

有一些认识了很多年、后来一直还在联系的朋友。

小老鼠觉得那里很自由。

所以后来，班里的同学和他渐渐聊不来的时候，他就更喜欢待在机房。

初二那年，他和同学之间发生了一些事情。

刚开始好像只是小孩子打闹，后来却慢慢变成了一些让他很难受的事情。

再后来，他多少有一点被边缘化了。

于是他更加往机房里面缩。

如果把一个人的青春比作一张地图，那么别人可能会在地图上画操场、教室、食堂、宿舍。

而小老鼠画出来的，是行政楼五楼。

五楼有很多间竞赛室。

五楼有机房。

五楼有他的朋友。

还有很多台电脑。

后来他上了高中。

他直升进了学校理科最尖的班。

那是一间很大的教室，里面坐着很多很厉害的人。

可是那年又遇到了疫情。

学校停课上了很久网课。

小老鼠和朋友们没有听课，而是一起打 NOIP。

如果一定要问他当时为什么这么做，他可能会很认真地把自己的脑袋剖开，然后说：

“50% 是想看看自己到底能走到哪里，有没有机会进省队。”

“40% 是想逃避高中。”

“还有 10%……我其实也不知道这东西到底有没有出路。”

所以那时候的小老鼠很矛盾。

他喜欢竞赛。

同时又躲在竞赛后面。

停课的那个学期，他确实很认真。

有模拟赛就打比赛、补题。

没比赛的时候，他会觉得：

“怎么感觉高级算法一个都不会。”

于是找专题继续做。

后来发现，好像很多也没真正用上。

他现在想起来，大概是因为那时候能力还不够，而且连高中数学基础都没有真正建立起来。

至于文化课怎么办。

那还能怎么办。

不就在 B 站看网课吗。

只是 B 站的网课有时候也不是完整的。

到了考试的时候，小老鼠自己估计了一下：

“大概只补回来七成。”

晚上他和朋友一起打比赛到很晚。

Codeforces 对他来说其实挺难。

有时候打到凌晨一点，他开始打不动了，就和朋友 ybh 打游戏。

那时候的小老鼠时间很少。

少到有时候连内耗都来不及。

可最后，他还是把事情搞砸了。

和他一起竞赛的同校学生也差不多。

教练没有真正帮他们解决文化课的问题。

小老鼠于是只好一个人，把语文、数学、英语、物理、化学、生物、地理一点一点捡回来。

别人学了一整个学期的东西，他要自己从头补。

那段时间，他觉得自己的天好像塌了一点。

但不知道为什么，他后来还是考回来了。

高一下分班考，他考了年级第二十六。

又回到了最尖的班。

他的朋友们没有一起回来。

小老鼠有一点爽。

他想：

“哦，我好像又行了。”

后来高一下的考试，他大多都能考进年级前十。

当然，他现在也知道，那时候的题其实没有特别难。

但是当时的他不知道。

当时的他只是觉得自己终于又能喘口气了。

而且那一年，还有一只小仓鼠。

她是小老鼠初中就认识的人。

他们初中就是同学，只是到了高中，她去了文科班。

认识了很多年，但直到高一下，他们才真正开始聊天。

一起上生物课。

随便说一点什么。

有一天，她在他的政治书上画了一个小小的向日葵笑脸。

还写过几封信。

每封信上都有可爱的表情和笑脸。

小老鼠后来想了很多遍。

她可能本来就是一只对很多人都很热情的小仓鼠。

但那时候的他，确实有一点心生爱慕。

而且这种喜欢很奇怪。

它没有什么惊天动地的故事。

只是会让他觉得：

“明天的生物课，好像也可以期待一下。”

同时高一下的每一个晚上，小老鼠都会以“竞赛”为理由去机房。

通常是他和两个次尖子班的朋友比较方便过去。

他们认识了很久，却其实没有想象中那么熟。

他们大多数时候在打游戏，看番剧。

小老鼠什么都看。

Final Fantasy。

一些很古早的演唱会。

乱七八糟的东西。

反正什么都吃。

现在回头看，他觉得那些晚上其实挺好的。

没有发生什么特别大的事情。

只是几个孩子坐在电脑前，打游戏，看东西，聊天，学一点东西。

外面的世界很吵。

而机房很安静。

那时候的小老鼠不知道，那其实已经是他整个中学里很难得的一段好日子了。

后来高二来了。

很多东西开始一点点变化。

那个小仓鼠不再和他一起上课。

机房里来了新的学弟。

高一和高二之间开始有一些复杂的人际关系。

甚至出现了三角恋。

这些事情本来和小老鼠没有什么直接关系。

可不知道为什么，他就是觉得难受。

不是“我想哭”的那种难受。

更像是身体先替脑子知道了：

这里已经发生变化了。

有一天，小老鼠突然意识到：

**原来自己最熟悉的那个地方，已经不是原来的地方了。**

还是五楼。

还是那些房间。

还是那些电脑。

可是已经不一样了。

偏偏高二又是最后一次 NOIP 的机会。

小老鼠原本打算：

“拿个一等奖，然后退出。”

给自己的竞赛生涯一个交代。

也可能是因为，他害怕自己再继续下去，会继续动摇。

可是那时候，他自己的状态已经很乱了。

教练没有什么办法。

身边一起竞赛的人也有的已经放弃、摆烂。

而他心里也乱得不得了。

而在某一天，他的教练对他说：

“反正你都已经废了。”

当然，这里说的是心理状态。

“那不如一废到底，去打 NOIP。”

他不解，但是他又去打了最后一次。

只拿了二等奖。

后来他一直嘴硬。

他说自己其实有一等奖实力。

这个话他不知道说给谁听。

也许说给朋友听。

也许说给自己听。

因为如果连这个都承认了，那些初中以来的东西，好像就真的只能停在二等奖这里了。

种种事情叠加，于是小老鼠彻底崩掉了。

他开始从生理上抗拒上课。

高二有一段时间，他总像一只老鼠一样，偷偷在五楼的竞赛室之间游荡。

当然，这次是真的像老鼠。

躲着老师。

不让老师发现自己又跑了。

因为自己是理科尖子班，班上有别的竞赛生，所以他可以去别的班、别的竞赛室待着。

可是他已经很久没有真正学习了。

成绩开始波动。

人也变得很奇怪。

他不是在认真玩。

也不是在休息。

而是在麻木地玩。

什么都不想干。

却又停不下来。

最奇怪的是，玩也一点都不快乐。

他知道马上就要高三了。

知道自己应该学习。

知道自己应该往前走。

可就是完全不想动。

有一天早上，小老鼠偷偷翘了课。

后来没能继续跑掉。

只好回到了教室。

坐下来以后，他突然觉得很难受。

他记得那种感觉。

好像教室里有很多双眼睛。

都在看他。

后来他才隐隐约约明白：

他好像已经不知道自己应该躲进哪里了。

机房不是以前的机房了。

教室也待得很难受。

他卡在中间。

然后高三来了。

也是到这个时候，他慢慢和班上的男生混熟了。

开始多说话。

一起玩。

一起熬高三。

直到现在上了大学，他们还每周一起打 CS2。

小老鼠也是到了那时候才发现：

原来班上的那些人，真的都很厉害。

而自己学得很吃力。

也学得很难受。

可是不管怎么样，高三最后还是过来了。

那些以前没有时间想的东西，大多数都被高考暂时盖住了。

他们就这样，压抑着，也快乐着，一起过完了高三。

高考结束那天，小老鼠其实没有想象中那么激动。

高三一年已经把很多情绪稀释掉了。

所以那一天，他更多的是解脱。

还有开心。

晚上，全家四口人也久违地一起待了很久。

至于他究竟是什么时候意识到：

“机房真的结束了。”

他自己也说不上来。

也许是高三某个时间段开始，他就已经慢慢接受了。

后来，小老鼠偶尔还会想一个问题：

如果自己从来没有学过信息学竞赛，会不会变成另一个人？

可他怎么想都想不出来。

因为那条世界线实在太不确定了。

如果没有竞赛，他还会不会学计算机？

会不会认识那些朋友？

会不会经历那些事情？

会不会喜欢过那只小仓鼠？

会不会成为现在这个样子？

谁都不知道。

所以小老鼠也不知道该怎么评价小时候的自己。

可怜？

有一点。

挺厉害？

有一点。

有点傻？

那确实是傻到没边了。

给自己压力？

这个从头到尾都是底层代码。

挺快乐？

其实也不算。

但如果一定要说一句什么，他大概还是会说：

**“他已经尽力了吧。”**

毕竟总不能再去压力过去的自己。

那个时候的他，也仍然只是一个小孩。

只是那个小孩后来长大了。

离开了五楼。

离开了机房。

离开了一群曾经围在电脑旁边的人。

现在他站在另一个很大的世界里，又开始烦恼完全不同的事情。

有时候他还是会想念过去。

有时候他甚至会希望自己能够重新走进那间机房。

可是他知道那已经不可能了。

因为童年不是一个地方。

青春也不是。

它更像一台已经关掉的旧电脑。

你记得它曾经亮过。

记得屏幕的光。

记得深夜。

记得有人在旁边笑。

记得自己曾经在里面认真地活过。

但它就是不会再开机了。

小老鼠对此其实还有很多想不明白。

他不知道如果换一条路会怎样。

不知道自己后来会变成什么样。

也不知道现在的自己到底算不算一个大人。

他只知道：

在很久以前，有一只小老鼠住在五楼。

那里有电脑，有代码，有游戏，有朋友。

有时候还有一轮向日葵的笑脸。

那只小老鼠曾经觉得，自己只要一直往前跑，总有一天可以证明自己到底有多厉害。

后来他没有证明出来。

但他也没有停在那里。

他只是走到了今天。

然后偶尔在很晚的时候，想起五楼。

想起那个还没有长大的自己。

觉得他有一点可怜。

又觉得他有一点厉害。

还觉得他真是傻到没边了。

想完以后，就继续往前走了。

因为五楼那盏灯，

已经关了很多年了。
